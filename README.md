Features

Edit Task
Delete Task
Update Status (Pending / Completed)

How to Run
1.Install XAMPP + Composer
2.composer install
3.Copy .env.example to .env, set DB_DATABASE=task_manager
4.php artisan key:generate
5.Create task_manager database in phpMyAdmin
6.php artisan migrate
7.php artisan serve
8.Open http://127.0.0.1:8000
